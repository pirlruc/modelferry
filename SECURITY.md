# Security policy

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Report it privately:

<https://github.com/pirlruc/modelferry/security/advisories/new>

Include a description, the affected version, and a way to reproduce it. You will get an acknowledgement within 7 days.

## Supported versions

Security fixes land on the default branch and ship in the next release. Older tags are not patched in place.

## What this covers

This repository's code and published packages. A finding in a third-party dependency is in scope when this package ships that dependency.
